# Dilithium per-instruction plots (φIF + TVLA)

Generated by `scripts/plot_regions.py`. Two detector families, written to `examples/plots/`
(the report references them as `../examples/plots/...` from `report/`). All PNGs listed below
exist on disk (regenerated Oct 9). Paths here are repo-relative.

## Regeneration

    python scripts/plot_regions.py

No argv. The script `os.chdir`s to repo root, loads `firmware/ml-dsa-44_m4f_test.elf`
(`Machine.from_elf` + `Scheme.bind`), `mkdir -p examples/plots`, then emits one PNG per
function in `BIG` (TVLA) and `PHI` (φIF). Prerequisites, all present:
- per-function instruction-skip dumps `dumps/<fn>_instrskip/meta.json` (A/B key captures + per-site records). A missing dump prints `(no dump)` and skips that plot.
- the ELF (symbol extents via `m.image.extent_of("pqcrystals_dilithium_<fn>")`).
- LLVM taint JSON `../Dilithium-LLVM/llvm/taintResults/pqcrystals_dilithium2_ref_<fn>.json` — only annotates the TVLA title; absent → "LLVM IR tainted: 0 instrs (none)".

Common layout: x = instructions in symbol order (disassembled start→end). ≤60 instrs → each
bar x-tick labelled `0xADDR mnemonic` (monospace, rotated); >60 instrs → "wide" mode, x is a
bare instruction index `0..N-1` with no per-bar labels. Figure width scales with instr count
(capped 22in), 140 dpi.

## (A) TVLA distribution-difference maps — `<fn>_by_instr.png`

Function family `BIG = [polyvecl_add, ntt, invntt_tomont, poly_uniform, poly_decompose,
poly_make_hint, poly_sub, polyvec_matrix_pointwise_montgomery]` (polyvecl_add first).

Built from `assess.assess_funcskip_from_dump(..., detector="per_coord")`. Bar height = per-instruction
`max|Welch t|` (A vs B), i.e. the strongest distribution difference the skip-at-that-PC experiment
produces between the two fixed keys.

Colors / axes:
- **red `#c0392b`** = LEAK (row status, FDR ≤ 0.01).
- **grey `#8a97a4`** = measured, no leak.
- **light `#d9dde1`** (+ vertical "crash" label in narrow mode) = skip crashed / no metric.
- dashed horizontal line at **TH = 4.5** = flag threshold (|t|≈4.5).
- title carries `n=` (message count) and the LLVM-IR tainted-instruction breakdown
  (e.g. `3 instrs (2×GetElementPtr, 1×Call)`).

Files present: `polyvecl_add`, `ntt`, `invntt_tomont`, `poly_uniform`, `poly_decompose`,
`poly_make_hint`, `poly_sub`, `polyvec_matrix_pointwise_montgomery` `_by_instr.png`
(+ a legacy `tvla_polyvecl_add_by_instr.png`).

### Reading `polyvecl_add_by_instr.png` — the key leak (mask add `z = z+y`)

13 instrs, narrow (labelled) mode, n=40, LLVM IR tainted = 3 (2×GetElementPtr, 1×Call).
**5 red LEAK bars**, the other bars grey (below 4.5) or crash:
- `0x46d2 mov r7, r0` — |t| ≈ 17 (saturated)
- `0x46dc adds r1, r6, r4` — |t| ≈ 4.5 (just over the line)
- `0x46e4 b.l 0x3d94` — |t| ≈ 17
- `0x46e8 cmp.w r4, #0x1000` — |t| ≈ 17
- `0x46ec bne #0x46da` — |t| ≈ 17 (loop back-edge)

Grey (no leak): `mov r6,r1`, `mov r5,r2`, `movs r4,#0`, `adds r2,r5,r4`, `add.w r4,#0x400`.
Crashes: prologue `push`, `add.w r4,r4,#0x400`, epilogue `pop`. The saturated bars are the
loop-control + call around the coefficient add — the ARM-side correlate of the z=z+y mask add.

## (B) φIF / ineffective maps — `<fn>_phi_by_instr.png`

Function family `PHI = [ntt, poly_challenge, polyvecl_uniform_gamma1, poly_chknorm]`.
Separate axis from TVLA — this is the **INEFFECTIVE** detector, not a distribution test.

`phi_by_pc(fn)` replays the dump: for each skip-site PC it compares, per message idx, the
skipped output to the golden output under key A and under key B, then counts messages where the
skip is a **no-op for exactly one key** (`effA[i] != effB[i]`) — a key-dependent-ineffective
(φIF) flip. Bar height = that count over the n messages per key.

Colors / axes:
- **purple `#8e44ad`** = φIF site (count > 0).
- **grey `#d9dde1`** = no key-split no-op.
- no threshold line; y-label `φIF flips (# of n=<n> msgs with a key-split no-op)`; title gives the
  site count, e.g. `purple = φIF site (63 sites)`.

Files present: `ntt`, `poly_challenge`, `polyvecl_uniform_gamma1`, `poly_chknorm` `_phi_by_instr.png`.

### Reading `ntt_phi_by_instr.png`

397 instrs → wide mode (bare index 0..396), n=40. **63 purple φIF sites**, grouped in four
clusters (~idx 15–32, 98–115, 193–210, 278–313) — the butterfly inner loops; heights 1–8 messages,
peaking at 8 (all A-no-op / B-effective, or vice-versa) in the ~idx 280 cluster. Each purple bar
is a single ARM instruction whose skip is ineffective under one key but output-changing under the
other — the key-dependent-ineffective surface the φIF/SIFA axis targets.

## Cross-reference

- `polyvecl_add` TVLA: **5 LEAK sites** (0x46d2, 0x46dc, 0x46e4, 0x46e8, 0x46ec), the mask-add
  `z=z+y` leak; LLVM flags 3 tainted IR instrs for the same function.
- `ntt` φIF: **63 φIF sites** across the four butterfly clusters — but note `ntt`'s TVLA map is a
  separate plot and the two detectors do not coincide (public-data distribution leaks ≠ the
